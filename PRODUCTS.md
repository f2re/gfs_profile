# Telegram products: aero and windgram

## Единый стиль графиков

Все PNG-продукты используют общий модуль `plot_style.py`.

Основные решения по UI/UX:

- светлый оперативный фон вместо дефолтного Matplotlib;
- приглушённая синоптическая сетка, не конкурирующая с данными;
- `T` — тёплый красно-оранжевый контур;
- `Td` — зелёный/бирюзовый контур;
- `0/-10/-20 °C` — синие изотермические ориентиры;
- ветер — тёмный нейтральный контур/барбы;
- windgram `param=wind` использует дискретную палитру скорости ветра: слабый ветер голубой, умеренный зелёно-жёлтый, сильный оранжево-красно-пурпурный;
- windgram `param=temp` использует температурную палитру: холодный фиолетово-синий → около 0°C светлый → тёплый жёлто-красный;
- windgram `param=rh` использует влажностную палитру: сухое бежевое/светло-зелёное → влажное синее;
- подписи сохраняют профессиональные обозначения `T`, `Td`, `RH`, `p`, `Z`, `V`, `UTC`, `гПа`, `м/с`, `км`.

Цель стиля — читаемый метеорологический продукт для оперативного анализа, а не технический график Matplotlib.

## Пошаговый Telegram-flow

Команды `/aero`, `/skewt` и `/windgram` без параметров запускают wizard:

```text
/aero
/skewt
/windgram
```

Сценарий:

1. Бот просит точку: город, координаты или Telegram-геолокация.
2. Если геокодер нашёл несколько вариантов, бот показывает inline-выбор точки.
3. После выбора точки бот показывает параметры продукта кнопками.
4. На этом же экране бот показывает готовую команду для копирования.
5. Кнопка `▶ Построить` запускает расчёт.

Для `/windgram` wizard даёт кнопки выбора поля заливки:

```text
Ветер       param=wind
Температура param=temp
Влажность   param=rh
```

Пример команды, которую wizard показывает после настройки:

```text
/aero 45.0000 39.0000 +24 type=skewt
/windgram 45.0000 39.0000 from=0 to=240 step=6 top=500 param=temp
```

Команды используют координаты, поэтому повторный запуск не зависит от неоднозначного геокодинга города. После построения `/windgram` бот дополнительно отправляет команду для точного повторения с зафиксированным `run=YYYYMMDD/HH`.

## Команды Telegram для регистрации

Централизованный список находится в `telegram_commands.py`. Зарегистрировать команды можно helper-скриптом:

```bash
TELEGRAM_BOT_TOKEN='123456:AA...' python register_telegram_commands.py
```

Список команд:

```text
start - 🚀 Старт и геолокация
help - ❓ Помощь и примеры
profile - 📈 Профиль GFS
aero - 🧾 Аэродиаграмма
skewt - 📉 Быстрая Skew-T
windgram - 🟦 Срок×уровень V/T/RH
cycle - 🕒 Последний цикл GFS
status - ⚙️ Статус и кэш
cancel - ✖️ Сброс выбора
```

## Аэрологическая диаграмма

Команды:

```text
/aero Москва +24
/aero 55.75 37.62 +48 type=stuve
/aero Санкт-Петербург run=20260701/00 +24 type=emagram
/skewt Москва +24
```

Поддерживаемые типы:

- `stuve` — режим по умолчанию для `/aero`.
- `emagram` — прямоугольная T-logP диаграмма.
- `skewt` — классическая Skew-T диаграмма, также доступна через `/skewt`.

Рендер строится через `MetPy + Matplotlib`. На диаграмму выводятся температура, точка росы, ветровые барбы, сухие и влажные адиабаты, линии отношения смеси, диагностический блок GFS с высотами изотерм `0/-10/-20 °C` и максимальным ветром. Продукт использует модельный изобарический профиль GFS по ближайшему узлу 0.25°, не фактический радиозонд.

## Windgram: срок × уровень

Команды:

```text
/windgram Москва
/windgram Москва to=120 param=wind
/windgram Москва to=120 param=temp
/windgram Москва to=120 param=rh
/windgram Москва to=384 step=6 top=500 param=wind
/windgram 55.75 37.62 run=20260701/00 from=0 to=120 step=6 top=500 param=temp
```

Параметры:

- `from` — начальный срок, часы, по умолчанию `0`.
- `to` — конечный срок, часы, по умолчанию `120`, максимум `384`.
- `step` — шаг по срокам, по умолчанию `6`.
- `top` — верхняя граница профиля по давлению, по умолчанию `500` гПа.
- `param=wind` — заливка и число по скорости ветра `V`, м/с.
- `param=temp` — заливка и число по температуре `T`, °C.
- `param=rh` — заливка и число по относительной влажности `RH`, %.
- `run=YYYYMMDD/HH` — фиксированный запуск GFS. Если не задан, бот выбирает один общий запуск по максимальному сроку windgram.

В каждой ячейке windgram:

- цветовая заливка показывает выбранный параметр;
- стрелка показывает направление переноса воздуха;
- число внутри ячейки показывает значение выбранного параметра.

Для широких диапазонов, например `to=384`, PNG отправляется как документ, чтобы Telegram не сжал изображение как фото.

## Архитектура

Новые модули:

```text
gfs_product_core.py        # level-aware загрузка профилей для продуктовых режимов
plot_style.py              # общая метеорологическая цветовая система и стиль Matplotlib
aero_plot.py               # MetPy renderer: Stuve/Emagram/SkewT
aero_product.py            # сборка aero product
windgram_product.py        # сборка time-height матрицы: V/T/RH + направление ветра
windgram_plot.py           # renderer ячеек: заливка параметра + стрелка + число
telegram_product_wizard.py # пошаговый Telegram UI для выбора точки и параметров
telegram_commands.py       # BotCommand definitions для меню Telegram
register_telegram_commands.py # helper регистрации slash-команд
telegram_aero.py           # Telegram command layer для /aero и /skewt
telegram_windgram.py       # Telegram command layer для /windgram
product_progress.py        # общий progress runner для продуктовых задач
```

Существующий `/profile` оставлен как базовый сценарий и не зависит от новых продуктовых команд, но использует тот же визуальный стиль.
