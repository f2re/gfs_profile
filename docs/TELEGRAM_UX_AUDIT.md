# Аудит пользовательских сообщений Telegram

## Обнаруженные проблемы

1. `/start` одновременно объяснял назначение, источники данных, форматы файлов и отдельные продукты.
2. `/help` содержал детали NOMADS, подложки, fallback и реализации карты.
3. Фразы «модель, не радар / не наблюдение / не радиозонд» повторялись в start, help, status, caption и footer.
4. Команды повтора сопровождались отдельной инструкцией по копированию.
5. Сообщения параметров повторяли назначение диаграммы после каждого нажатия кнопки.
6. Progress показывал внутренние названия `GRIB2`, `cfgrib`, `eccodes`, `forecast-файл` и `NOMADS`.
7. Reply-клавиатура с запросом геолокации создавалась как постоянная и оставалась после выбора точки.
8. Меню Bot API могло оставаться старым из-за более специфичных scope/language команд.

## Принятые решения

- `/start`: короткое назначение и inline-меню продуктов.
- `/help`: три шага работы, четыре примера и служебные команды.
- геолокация: временная reply-клавиатура только в состоянии `await_point`;
- после выбора точки reply-клавиатура удаляется;
- параметры и навигация: inline-кнопки;
- `/cancel`: очистка сценария, удаление reply-клавиатуры, возврат главного меню;
- progress: пользовательские этапы без названий внутренних библиотек;
- captions: продукт, GFS run, срок, точка и только существенные отсутствующие поля;
- repeat: одна строка `<code>команда</code>`;
- общий научный дисклеймер: один раз в итоговой сводке или footer PNG;
- регистрация команд: очистка stale default/private и ru/en scope перед записью нового списка.

## Матрица стадий

| Стадия | Сообщение | Клавиатура |
|---|---|---|
| Главное меню | Что умеет бот | Inline products |
| Ожидание точки | Город, координаты или геолокация | Temporary reply keyboard |
| Неоднозначная точка | Выберите вариант | Inline candidates |
| Параметры | Точка + одна строка настроек | Inline parameters |
| Progress | Продукт + срок + этап | Нет |
| Результат | Run + срок + существенные данные | Нет |
| Повтор | Одна команда | Нет |

## Проверки

- start < 500 символов;
- request-location отсутствует в главном меню;
- `one_time_keyboard=true`, `is_persistent=false`;
- клавиатура сохраняется при ошибке ввода точки и удаляется после успешного выбора;
- progress не содержит `cfgrib/eccodes/NOMADS`;
- map status не содержит повтор «не радар / не наблюдение»;
- меню команд синхронизируется для default/all-private и языка `ru`;
- runtime импортирует весь UX-слой.
