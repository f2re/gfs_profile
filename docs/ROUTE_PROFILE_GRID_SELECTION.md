# Выбор сетки маршрутного профиля

Пользователь выбирает пространственный шаг вдоль маршрута:

- `25 км` — максимальная детализация;
- `50 км` — сбалансированный режим;
- `100 км` — быстрый обзор длинного маршрута.

Если выбранный шаг создаёт 60 и более расчётных точек, бот показывает предупреждение и количество точек для всех вариантов. Длинный прямой запрос без `step=` сначала переводится на экран выбора детализации.

Название пункта сохраняется ровно в том виде, как его ввёл пользователь, и используется в заголовке PNG, статусе, caption и repeat-команде. Геокодер отвечает только за координаты.
