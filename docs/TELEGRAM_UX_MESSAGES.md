# Контракт сообщений и клавиатур Telegram

## Цель

Сообщение должно помогать выполнить следующий шаг. Технические пояснения, архитектура источников и повторяющиеся дисклеймеры не должны занимать основной экран.

## Начальное сообщение

`/start` содержит:

- одно предложение о назначении бота;
- краткое назначение основных продуктов;
- inline-кнопки выбора продукта.

В `/start` не повторяются формулировки «не радар», «не наблюдение», «не радиозонд». Научная маркировка остаётся в итоговой продукции и footer PNG.

## Справка

`/help` содержит только:

1. общий порядок действий;
2. четыре коротких примера;
3. служебные команды `/cycle`, `/status`, `/cancel`.

Детали реализации NOMADS, Natural Earth, fallback и форматы внутренних слоёв не выводятся пользователю.

## Стадии клавиатуры

### Главное меню

Используется inline-клавиатура:

- профиль;
- маршрут;
- облака;
- срок × уровень;
- аэродиаграмма;
- карта;
- помощь.

Она не заменяет системное меню команд Telegram.

### Выбор точки

Только на этой стадии показывается временная reply-клавиатура:

- `📍 Моя геолокация`;
- до четырёх последних точек;
- `✖ Отмена`.

Параметры клавиатуры:

```text
one_time_keyboard = true
is_persistent = false
selective = true
```

После выбора точки клавиатура удаляется. Параметры продукта выбираются inline-кнопками.

### Изменение точки

Кнопка «Изменить точку» повторно включает reply-клавиатуру геолокации. После нового выбора она снова удаляется.

### Отмена

`/cancel` и кнопка `✖ Отмена`:

- очищают активный сценарий;
- удаляют reply-клавиатуру;
- возвращают inline-главное меню.

## Параметры продукта

Сообщение содержит максимум:

- название продукта;
- выбранную точку;
- одну строку текущих параметров;
- команду повтора.

Объяснения значения графика должны находиться на самом PNG или в отдельной документации, а не повторяться при каждом изменении кнопки.

## Progress

Статус содержит:

- продукт;
- точку;
- срок или диапазон;
- текущий этап.

Не повторяются общие дисклеймеры.

## Итог

Подпись результата содержит только:

- продукт;
- run GFS и срок;
- точку или маршрут;
- критически важное предупреждение об отсутствующем поле.

Команда повтора выводится одной строкой `<code>…</code>` без инструкции «нажмите и скопируйте».

## Научная маркировка

Фраза о модельной природе данных остаётся один раз:

- в footer итогового PNG;
- либо в компактной текстовой сводке, когда PNG отсутствует.

Её не нужно повторять в `/start`, `/help`, progress, caption и команде повтора.

## Критерии приёмки

- `/start` короче 500 символов;
- начальный экран перечисляет основные продукты;
- кнопка геолокации отсутствует на главном экране;
- request-location появляется только при ожидании точки;
- после выбора точки reply-клавиатура скрывается;
- параметры используют inline-кнопки;
- `/cancel` возвращает главное меню;
- map status не содержит повторяющийся текст «не радар / не наблюдение»;
- repeat-сообщение состоит из одной команды;
- unit tests проверяют типы и параметры клавиатур.
