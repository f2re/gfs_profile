# Рендер маршрутного вертикального профиля

## Разделение расчёта и отображения

Исходные точки GFS, вертикальные поля, диагностические маски и категории риска общие для `simple` и `pro`. Рендер не изменяет:

- `point_risk`;
- `icing_score`;
- `turbulence_score`;
- `cloud_mask`;
- грозу, осадки, видимость и ВНГО;
- границы карточек маршрута.

Для PNG строится отдельная display-сетка. Сглаживание применяется только к ней и не попадает в CSV или расчёт риска.

## Display grid

`route_profile_smoothing.py` выполняет:

1. PCHIP-интерполяцию вдоль маршрута;
2. интерполяцию между изобарическими уровнями;
3. NaN-aware Gaussian smoothing;
4. для `simple` — морфологическое замыкание/очистку визуальных масок;
5. расчёт компоненты ветра вдоль маршрута для направления декоративных потоков.

### Простой режим

- до 480 точек по горизонтали;
- 101 display-уровень по давлению;
- более сильное сглаживание по маршруту;
- мягкие связные области облачности, льда и болтанки;
- непрерывный температурный градиент;
- векторные пиктограммы без зависимости от emoji-шрифтов;
- округлённые карточки участков.

### Профессиональный режим

- до 360 точек по горизонтали;
- 73 display-уровня;
- минимальное сглаживание только для устранения ступенчатости;
- исходные точки GFS сохраняются для ветровых барб;
- дискретные контуры и разреженная штриховка;
- RH 80/90%, красные изотермы и изотахи V20/V30/V40;
- числовые карточки участков.

## Модули

```text
route_profile_visual_style.py          единая палитра и alpha

route_profile_render_professional.py   академический pro
route_profile_rendering.py             диспетчер режима и stable API patch
```

## Облачность

В `simple` облачность формируется из исходной облачной маски и RH, затем мягко сглаживается. Отображение состоит из полупрозрачных серо-голубых масс и редких векторных облаков. Это визуальная интерпретация модельного облачного слоя, а не фотореалистичное изображение.

В `pro` показываются только тонкие контуры `CLD` и `CLD dense`, без декоративных облаков.

## Обледенение и болтанка

Исходная интенсивность берётся из объективных score 0–3.

- `simple`: плавная цветная заливка, мягкая граница, крупная векторная пиктограмма и подпись;
- `pro`: пороги `ICE1/ICE2+` и `TURB1/TURB2+`, цветная разреженная штриховка и числовая/буквенная маркировка.

## Ветер

- `simple`: плавные зоны сильного ветра, изотахи и редкие стрелочные маркеры направления вдоль маршрута;
- `pro`: изотахи V20/V30/V40 и барбы на исходных маршрутных точках GFS.

Стрелки `simple` являются способом представления и не используются в расчёте риска.

## Температура и влажность

- `simple`: непрерывный приглушённый градиент и тонкие мягкие изотермы;
- `pro`: очень слабый фон, красные изотермы 0/-10/-20 °C и RH 80/90%.

## Иконографика

Иконки строятся Matplotlib-примитивами:

- облако;
- снежинка;
- турбулентный поток;
- ветер;
- гроза;
- осадки.

Такой подход одинаково работает на сервере без цветных emoji-шрифтов.

## Ограничения

Сглаженная граница не означает повышение разрешения GFS. Нативная модель остаётся GFS 0.25°. Display-grid улучшает читаемость, но не добавляет новую физическую информацию.
