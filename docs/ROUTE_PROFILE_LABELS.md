# Названия пунктов в `/route`

Введённое пользователем название пункта является частью запроса и не заменяется координатами после геокодирования. Оно используется в заголовке PNG, статусном сообщении, подписи файла, статистике и команде повтора.

Если пользователь вводит координаты, показывается полная пара `широта долгота`, а не только широта.
