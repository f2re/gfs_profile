# Changelog рендера `/route`

## 2026-07-12

- расчёт и display-сетка разделены;
- добавлена PCHIP-интерполяция и NaN-aware Gaussian smoothing;
- `simple` получил непрерывный температурный градиент, мягкие облачные массы, плавные зоны рисков, векторные иконки, потоки ветра и округлённые карточки;
- `pro` получил сдержанный академический стиль: слабый фон T, CLD, ICE/TURB-пороги, RH80/90, красные изотермы, V20/V30/V40 и барбы на исходных точках;
- objective risk и карточки остаются одинаковыми для обоих режимов;
- старый `route_profile_simple_overlay.py` удалён;
- добавлены smoke-тесты PNG и тесты display smoothing.
