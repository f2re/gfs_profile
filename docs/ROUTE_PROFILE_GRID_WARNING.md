# Предупреждение долгого расчёта `/route`

Предупреждение показывается, если выбранная сетка создаёт 60 и более расчётных точек. Бот выводит:

- выбранный шаг;
- оценку количества точек;
- варианты 25/50/100 км;
- пояснение, что 50 и 100 км сокращают время расчёта.

Прямой длинный запрос без `step=` не запускается немедленно: пользователь сначала подтверждает детализацию кнопкой.
