# Персональный Telegram UX

## Цель

Бот сохраняет пользовательский контекст и сокращает типовой сценарий до одного-двух нажатий. Сохраняются только подтверждённые точки и валидированные параметры продуктов. Продукция по-прежнему маркируется как модель GFS, не наблюдение и не радиозонд.

## Приоритет параметров

```text
явные параметры команды
→ текущий сохранённый выбор пользователя
→ последний успешный расчёт
→ системные значения по умолчанию
```

`run=YYYYMMDD/HH`, выбранный GRIB-файл, статусные сообщения, кандидаты геокодинга и другие временные данные не сохраняются. Быстрый повтор всегда выбирает актуальный опубликованный цикл, в котором существует максимальный запрошенный срок.

## Основная точка

Первая успешно выбранная точка становится основной. Следующие интерактивные выборы обновляют её. Точки маршрута сохраняются в истории, но не заменяют основную точку для профиля, карты и других точечных продуктов.

В `/settings` доступны:

- выбор основной точки из последних десяти;
- сброс параметров отдельного продукта;
- очистка истории точек без удаления расписаний;
- удаление всех персональных точек и параметров.

`/cancel` очищает только текущий мастер и возвращает персональное главное меню.

## Карта по умолчанию

Первый интерактивный запуск `/map` получает профессионально полезный вариант:

```text
режим: анимация
диапазон: +0…+48 ч
шаг: 3 ч
кадров: 17
радиус: 100 км
подложка: places
```

Для диапазонов 72 и 96 часов шаг автоматически увеличивается до совместимого значения, чтобы не превышать ограничение 18 кадров. Настройки режимов `animation`, `single` и `series` хранятся независимо: переход к одной карте не стирает диапазон анимации.

Явная команда сохраняет прежнюю семантику:

```text
/map Москва +24                         одна карта
/map Москва from=0 to=72 step=6 mode=gif
```

Команда `/map Москва` без временных параметров использует сохранённый вариант, а для нового пользователя — анимацию 48 часов.

## Быстрые действия

После успешного интерактивного расчёта сохраняются продукт, точка и параметры. На `/start` выводятся не более двух быстрых действий:

1. последний успешно использованный продукт;
2. наиболее часто успешно используемый отличный вариант.

Автоматические отправки по расписанию не меняют интерактивные настройки. Расписание хранит собственный снимок параметров.

## Значения первого запуска

| Продукт | Параметры |
|---|---|
| Профиль | `+24 ч` |
| Аэродиаграмма | Skew-T, `+24 ч` |
| Срок × уровень | ветер, `+0…+120 ч`, шаг 6 ч, до 500 гПа |
| Облака | подробно, `+0…+72 ч`, шаг 3 ч |
| Карта | анимация `+0…+48 ч`, шаг 3 ч |
| Метеограмма | GFS, 5 суток, PNG |
| Маршрут | `+24 ч`, 300 км/ч, простой режим, сетка 50 км |

## Хранилище

По умолчанию используется:

```text
.cache_gfs/telegram_preferences.sqlite3
```

Путь настраивается переменной:

```env
TELEGRAM_PREFERENCES_DB=.cache_gfs/telegram_preferences.sqlite3
```

SQLite работает в режиме WAL. Внешняя БД, Redis, Celery или отдельный процесс не требуются. Штатный deploy сохраняет `.cache_gfs`, поэтому точки и параметры переживают обновление и перезапуск сервиса.

## Проверка

```bash
python -m unittest discover -s tests
python runtime_check.py
python -m gfs_core --lat 45.0355 --lon 38.9753 --lead 24
python -m gfs_core --lat 55.75 --lon 37.62 --lead 384
```

Ручные Telegram-сценарии:

```text
/start → выбрать точку → карта → анимация 48 ч
/start → быстрое действие → повтор на актуальном цикле
/settings → сменить основную точку
/map Москва → сохранённый/default диапазон
/map Москва +24 → одна карта
/cancel → главное меню без потери настроек
```
