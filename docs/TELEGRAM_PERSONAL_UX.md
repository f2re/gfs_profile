# Персональный Telegram UX

## Приоритет состояния

```text
явные параметры команды
→ закреплённый recipe продукта
→ текущий сохранённый выбор / последний успешный вариант
→ системный default
```

`run/cycle`, message ids, кандидаты геокодинга и wizard state не сохраняются. Повтор всегда выбирает актуальный опубликованный цикл GFS.

## Основная точка

Первая успешно выбранная точка становится основной. Интерактивные выборы могут её обновлять. Точки маршрута сохраняются в истории, но не заменяют основную точку точечных продуктов.

`/settings` позволяет выбирать основную точку, просматривать сохранённые сценарии, сбрасывать продукт и удалять персональные данные. `/cancel` очищает только текущий мастер.

## Карта по умолчанию

```text
режим: анимация
диапазон: +0…+48 ч
шаг: 3 ч
кадров: 17
радиус: 100 км
подложка: places
```

Для 72/96 часов шаг автоматически нормализуется, чтобы не превысить 18 кадров. Настройки анимации, одной карты и серии PNG хранятся независимо.

`/map Москва +24` остаётся одной картой. `/map Москва` использует закреплённый/сохранённый вариант, а для нового пользователя — анимацию 48 часов.

## Сохранённые сценарии

Успешный расчёт сохраняется как отдельный recipe `product + point + params`, поэтому разные варианты одного продукта не вытесняют друг друга.

После результата доступны:

```text
🔄 Обновить
⚙️ Изменить
☆ Закрепить / ★ Открепить
🕒 В расписание
🏠 Главное меню
```

Кнопки адресуют конкретный `recipe_id`; старое сообщение не может случайно изменить другой последний расчёт. `В расписание` переносит snapshot выбранного recipe.

`/settings → Сохранённые сценарии` позволяет открыть, повторить, изменить, закрепить, поставить в расписание и удалить сценарий.

## Быстрые действия

На `/start` выводится не более двух quick recipes. Закреплённые идут первыми; далее учитываются последний успешный и частота использования. Допустимы два разных состояния одного продукта — например карта Краснодара 48 ч и карта Москвы 96 ч.

Автоматические отправки не меняют интерактивные defaults и не увеличивают пользовательскую частоту.

## Первый запуск продуктов

| Продукт | Default |
|---|---|
| Профиль | `+24 ч` |
| Аэродиаграмма | Skew-T, `+24 ч` |
| Срок × уровень | ветер, `+0…+120 ч`, шаг 6 ч, до 500 гПа |
| Облака | подробно, `+0…+72 ч`, шаг 3 ч |
| Карта | анимация `+0…+48 ч`, шаг 3 ч |
| Метеограмма | GFS, 5 суток, PNG |
| Маршрут | `+24 ч`, 300 км/ч, простой режим, сетка 50 км |

## Хранилище

```env
TELEGRAM_PREFERENCES_DB=.cache_gfs/telegram_preferences.sqlite3
```

SQLite работает в WAL и сохраняется штатным deploy вместе с `.cache_gfs`. Redis/Celery/внешняя БД не требуются.

Подробный recipe contract: `docs/MESSENGER_SAVED_RECIPES.md`.
