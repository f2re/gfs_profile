# 🤖 Telegram-бот GFS

Бот строит вертикальные, временные, маршрутные и картографические продукты GFS 0.25° по городу, координатам или Telegram-геолокации.

## Основные команды

```text
/start      главное меню
/help       краткая инструкция
/cancel     сброс выбора
/cycle      последний цикл GFS
/status     доступность сроков и кэш
/profile    вертикальный профиль
/route      профиль по маршруту
/aero       аэрологическая диаграмма
/skewt      быстрая Skew-T
/windgram   срок × уровень
/cloudgram  облака, осадки и грозы
/map        карта, серия или анимация
/admin      статистика и отчёты
```

Примеры:

```text
/profile Москва +24
/route Москва -> Санкт-Петербург +24 speed=300 step=50 mode=pro
/cloudgram Москва to=72 mode=simple
/map Москва from=0 to=24 step=3 mode=gif
```

## Начальный экран

`/start` показывает:

- одно короткое описание;
- назначение основных команд;
- inline-кнопки продуктов.

На начальном экране нет постоянной кнопки геолокации. Общие пояснения «не радар / не наблюдение / не радиозонд» не повторяются в пользовательских шагах.

## Адаптивные клавиатуры

### Главное меню

Используется inline-клавиатура:

```text
Профиль | Маршрут
Облака  | Срок × уровень
Аэродиаграмма | Карта
Как пользоваться
```

### Ожидание точки

Reply-клавиатура появляется только после выбора продукта, которому нужна точка:

```text
📍 Моя геолокация
до четырёх последних точек
✖ Отмена
```

Она настроена как временная:

```text
one_time_keyboard=true
is_persistent=false
selective=true
```

После выбора точки клавиатура удаляется. Следующая стадия использует inline-кнопки параметров.

### Изменение точки

Кнопка изменения точки повторно открывает только клавиатуру геолокации. После выбора она снова скрывается.

### Отмена

`/cancel` и `✖ Отмена`:

- очищают profile/product/route wizard;
- удаляют reply-клавиатуру;
- показывают главное inline-меню.

## Контракт сообщений

Пользовательское сообщение отвечает на один вопрос: что происходит сейчас или что нужно сделать дальше.

- `/start` — что умеет бот;
- prompt — один следующий шаг;
- параметры — точка и одна строка настроек;
- progress — продукт, точка, срок и этап;
- результат — run, срок и существенные данные;
- повтор — одна команда `<code>…</code>`.

Технические детали NOMADS, Natural Earth, fallback-провайдеров и архитектуры кэша не выводятся в обычном UX.

Научная маркировка сохраняется один раз в итоговой сводке или footer PNG.

Подробно: `docs/TELEGRAM_UX_MESSAGES.md`.

## Progress

Для долгих операций бот обновляет одно статусное сообщение. Для `/route` дополнительно показываются номер точки, расстояние, ETA, выбранная сетка и число точек.

## Маршрутный профиль `/route`

```text
/route
Москва -> Санкт-Петербург
выбрать срок
выбрать скорость
выбрать сетку 25/50/100 км
выбрать Упрощённый или Профи
```

При 60 и более точках бот предупреждает о времени расчёта и предлагает увеличить шаг.

`simple` и `pro` используют одинаковые исходные поля, `point_risk`, границы и категории карточек. Отличается только представление.

### Упрощённый режим

- умеренное сглаживание без слияния раздельных зон;
- мягкие облачные массы;
- существенные зоны льда, болтанки и ветра;
- ограниченное количество подписей;
- адаптивные карточки по 100–120 км.

### Профессиональный режим

- минимальное сглаживание;
- CLD, ICE, TURB, RH80/90;
- красные изотермы;
- V20/V30/V40 и барбы;
- числовые карточки R0–R3, Vmax, P, VIS и ВНГО.

## Геокодирование

Основной провайдер — DaData Suggestions. Локальный словарь и Nominatim используются как fallback согласно `GEOCODER_PROVIDERS`.

## Установка и обновление

```bash
bash install_telegram_bot.sh
```

После `git pull`:

```bash
git checkout telegram-bot
git pull
python -m unittest discover -s tests
python runtime_check.py
sudo bash deploy_telegram_bot.sh --yes
sudo bash deploy_telegram_bot.sh --status
sudo systemctl status gfs-profile-bot.service
```

## Важно

Сглаженный PNG не повышает физическое разрешение GFS. Маршрутный продукт не является разрешением на полёт.
