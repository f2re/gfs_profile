# 🤖 Telegram-бот GFS

Бот строит модельные вертикальные, временные и картографические продукты GFS 0.25° по городу, координатам или Telegram-геолокации.

Это модельная сетка GFS, не радиозонд, не метеостанция и не наблюдение.

## Основные команды

```text
/start      старт и геолокация
/help       инструкция
/cancel     сброс выбора
/cycle      последний опубликованный анализ GFS
/status     доступность сроков и состояние кэша
/profile    вертикальный профиль по точке
/route      вертикальный профиль по маршруту
/aero       аэрологическая диаграмма
/skewt      быстрая Skew-T
/windgram   срок × уровень
/cloudgram  облачность, осадки, грозы
/map        карта, серия PNG или MP4-анимация
/admin      статистика и отчёты
```

Примеры:

```text
/profile Москва +24
/route Москва -> Санкт-Петербург +24 speed=300 step=50 mode=pro
/route 55.75 37.62 -> 59.94 30.31 +6 speed=450 step=25 mode=simple
/map Москва from=0 to=24 step=3 mode=gif
```

## Progress

Для долгих операций бот обновляет одно статусное сообщение:

```text
1/5 Проверяю публикацию forecast-файла
2/5 Привязываю точку к узлу GFS
3/5 Скачиваю GRIB2
4/5 Читаю xarray/cfgrib/eccodes
5/5 Формирую сводку, PNG и CSV
```

Для `/route` дополнительно показываются номер точки, расстояние, ETA, выбранная сетка и общее число точек.

## Маршрутный профиль `/route`

### Сценарий

```text
/route
Москва -> Санкт-Петербург
выбрать вылет +0/+6/+12/+24/+48 ч
выбрать 150/300/450/600 км/ч
выбрать сетку 25/50/100 км
выбрать Простой или Профи
```

### Названия пунктов

Если пользователь вводит название пункта, оно сохраняется в запросе и выводится:

- в заголовке PNG;
- в статусе расчёта;
- в caption;
- в admin-статистике;
- в repeat-команде.

Геокодер используется только для координат. Он не заменяет введённое название координатами. Если введены координаты, отображается полная пара широта/долгота.

### Выбор пространственного шага

```text
25 км  — максимальная детализация
50 км  — баланс детализации и времени
100 км — быстрый обзор длинного маршрута
```

Прямой синтаксис:

```text
step=25
step=50
step=100
```

Если выбранная сетка создаёт 60 и более расчётных точек, бот показывает предупреждение и оценку числа точек для всех трёх вариантов. Длинный прямой запрос без `step=` не запускается немедленно: пользователь сначала выбирает детализацию кнопками.

### Расчёт

- точки строятся по дуге большого круга;
- ETA = расстояние / средняя скорость;
- срок GFS = `lead вылета + ETA`;
- скорость изменяет ETA, но не геометрию точек;
- `step` изменяет число пространственных точек;
- каждая точка привязывается к ближайшему узлу GFS;
- эксплуатационный лимит — 161 точка.

### Объективный риск

Риск рассчитывается отдельно для каждой точки и не зависит от `mode`.

Для одинакового запроса `simple` и `pro` используют одинаковые:

```text
точки маршрута
GFS-сроки
point_risk
icing_score
turbulence_score
cloud_mask
гроза/осадки
видимость и ВНГО
границы карточек
категории риска карточек
```

`simple` меняет только представление: пиктограммы, короткие подписи и четыре ключевых уровня. `pro` добавляет барбы, V20/V30/V40, красные изотермы, RH и числовые параметры.

Подробно:

```text
docs/ROUTE_PROFILE.md
docs/ROUTE_PROFILE_VISUAL_REQUIREMENTS.md
docs/ROUTE_RISK_CONTRACT.md
```

## Карта `/map`

`mode=gif` при наличии `ffmpeg` создаёт silent H.264/MP4 и отправляет Telegram animation. GIF используется как fallback.

## Admin

```text
TELEGRAM_ADMIN_IDS=123456789,987654321
TELEGRAM_ADMIN_DB=.cache_gfs/admin_stats.sqlite3
```

Команды:

```text
/admin
/admin stats 30
/admin recent 20
/admin users
/admin find @username
/admin add @username
/admin add 123456789
/admin report requests 30
/admin report users
```

## Установка и обновление

```bash
bash install_telegram_bot.sh
```

После `git pull`:

```bash
git checkout telegram-bot
git pull
python -m unittest discover -s tests
python runtime_check.py
bash deploy_telegram_bot.sh --yes
bash deploy_telegram_bot.sh --status
sudo systemctl status gfs-profile-bot.service
sudo journalctl -u gfs-profile-bot.service -n 100 --no-pager
```

## Важно

Маршрутный продукт не определяет юридическую или фактическую возможность полёта. Красная категория означает высокий модельный риск, а не закрытое воздушное пространство. Перед полётом обязательны актуальные METAR/TAF/SIGMET/GAMET, NOTAM, данные диспетчерских и решение командира.
