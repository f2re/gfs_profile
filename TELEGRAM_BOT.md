# 🤖 Telegram-бот GFS

Бот строит вертикальные, временные, маршрутные и картографические продукты GFS 0.25° по городу, координатам или Telegram-геолокации.

## Основные команды

```text
/start      главное меню
/help       краткая инструкция
/cancel     сброс выбора
/cycle      последний цикл GFS
/status     доступность сроков и кэш
/profile    вертикальный профиль
/route      профиль по маршруту
/aero       аэрологическая диаграмма с годографом
/windgram   срок × уровень
/cloudgram  облака, осадки и грозы
/map        карта, серия или анимация
/admin      статистика и отчёты
```

`/skewt` удалена из обработчиков и системного меню Telegram. Пользователь не выбирает Stüve/Emagram/Skew-T: `/aero` всегда строит Skew-T log-P с годографом.

Примеры:

```text
/profile Москва +24
/route Москва -> Санкт-Петербург +24 speed=300 step=50 mode=pro
/aero Москва +24
/cloudgram Москва to=72 mode=simple
/map Москва from=0 to=24 step=3 mode=gif
```

## Начальный экран

`/start` простыми словами перечисляет все команды и показывает inline-кнопки продуктов. На начальном экране нет постоянной кнопки геолокации.

Reply-клавиатура геолокации появляется только на стадии ожидания точки и удаляется после выбора.

## Аэрологическая диаграмма

Wizard `/aero` содержит только:

```text
выбор точки
выбор срока
построить
```

Переключатель типа диаграммы отсутствует.

Выходной PNG содержит:

- Skew-T log-P;
- температуру среды красным;
- точку росы зелёным;
- кривую частицы чёрным;
- насыщение надо льдом синим пунктиром;
- уровень конденсации и высоту в метрах;
- изотермы 0/-10/-20 °C;
- облачность, обледенение и болтанку;
- ключевые индексы без пересечения подписей;
- ветер, сдвиг и годограф 0–8 км.

Историческая статистика `skewt` в `/admin` объединяется с `aero`.

Подробно: `docs/AERO_DIAGRAM.md`.

## Адаптивные клавиатуры

Главное меню — inline. Reply-клавиатура `📍 Моя геолокация` показывается только при выборе точки:

```text
one_time_keyboard=true
is_persistent=false
selective=true
```

`/cancel` удаляет reply-клавиатуру и возвращает главное меню.

## Progress

Для долгих операций бот обновляет одно статусное сообщение. Пользователь видит продукт, точку, срок и текущий этап без названий внутренних библиотек.

## Маршрутный профиль `/route`

```text
/route
Москва -> Санкт-Петербург
выбрать срок
выбрать скорость
выбрать сетку 25/50/100 км
выбрать Упрощённый или Профи
```

`simple` и `pro` используют одинаковые исходные поля и категории риска. Отличается только представление.

## Геокодирование

Основной провайдер — DaData Suggestions. Локальный словарь и Nominatim используются как резерв согласно `GEOCODER_PROVIDERS`.

## Установка и обновление

```bash
bash install_telegram_bot.sh
```

После `git pull`:

```bash
git checkout telegram-bot
git pull
python -m unittest discover -s tests
python runtime_check.py
sudo bash deploy_telegram_bot.sh --yes
sudo bash deploy_telegram_bot.sh --status
sudo systemctl status gfs-profile-bot.service
```

Deploy перерегистрирует меню Telegram, поэтому `/skewt` исчезает из default/all-private и русскоязычного scope.

## Важно

Диагностические слои аэрологической диаграммы рассчитаны по полям GFS и не являются наблюдением или радиозондом.
