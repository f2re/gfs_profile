# Полная аэрограмма GFS

`/aero` и `/skewt` строят одну PNG-аэрограмму по ближайшему узлу GFS 0.25. Это модельный профиль, не радиозонд и не наблюдение.

## Что показано на PNG

- T — кривая температуры.
- Td — кривая точки росы.
- Кривая частицы — подъём нижнего доступного уровня профиля.
- CAPE — положительная плавучесть, энергия неустойчивости.
- CIN — отрицательная плавучесть, подавление конвекции.
- LCL — уровень конденсации.
- LFC — уровень свободной конвекции.
- EL — уровень равновесия.
- 0 / −10 / −20 °C — интерполированные высоты изотерм по T(z).
- Барбулы — ветер U/V GFS, м/с; направление метеорологическое, откуда дует.
- Годограф 0–8 км — профиль ветра по высоте.
- Правая колонка — диагностические слои опасности по той же оси давления.

## Диагностические слои

```text
Обл   облачность: RH≥85% или RH≥78% при T−Td≤3 °C
Лёд   риск обледенения: влажный слой при 0…−20 °C
Турб  риск турбулентности: Ri<0.25 или сдвиг ветра ≥8 м/с/км
КНС   конвективно неустойчивый слой: dθe/dz≤−3 K/км
Ос    слой гидрометеоров, если соответствующие поля есть в профиле
```

Число в полосе слоя — условная интенсивность 1–5. Это не наблюдённое явление, а расчетная модельная диагностика по GFS.

## Индексы в нижнем блоке

```text
SBCAPE/CIN   CAPE/CIN для частицы нижнего уровня
MLCAPE/CIN   CAPE/CIN для смешанного слоя MetPy
MUCAPE/CIN   CAPE/CIN для наиболее неустойчивой частицы MetPy
LCL/LFC/EL   основные уровни конвекции, гПа
PWAT         осаждаемая вода, мм
TT/K         Total Totals и K-index
Vmax         максимум скорости ветра в профиле
max shear    максимум вертикального сдвига ветра, м/с/км
min Ri       минимум градиентного числа Ричардсона
```

## Ограничения

- По одному изобарическому профилю нельзя честно подтвердить факт осадков, грозы, обледенения или болтанки. PNG показывает риск/потенциал.
- Приземный слой зависит от орографии и первого доступного изобарического уровня GFS.
- Осадки и гидрометеоры отображаются только при наличии соответствующих полей в GRIB-профиле; базовый профиль может их не содержать.
- Все подписи на графике русские; технические сокращения расшифрованы в легенде.
