# WeatherNext 3 — предварительный выпуск RC2

## Обычный прогноз больше не спрятан в ансамблях

В обычном выборе моделей появился **WeatherNext 3 · средний прогноз**.
В `/wn3` «Метеограмма» показывает среднее без полос разброса, а отдельный
«Ансамбль» — среднее и квантили. Обе кнопки доступны через общий сценарий
Telegram, MAX и VK. Все представления используют один BigQuery-провайдер;
средний прогноз честно подписан как среднее ансамбля, не новая детерминированная модель.

```text
/wn3 Москва kind=meteogram days=5
/wn3 Москва kind=ensemble days=5
/meteogram Москва source=weathernext3_mean days=5
/meteogram Москва source=weathernext3 days=5
```

Старый `source=weathernext3` остаётся ансамблевым для совместимости с командами
и расписаниями. `/wn3 kind=meteogram` теперь означает среднее без полос разброса;
для прежнего отображения квантилей нужен `kind=ensemble`. Доступны PNG/DOCX/PDF
и CSV. Обновлена документация трёх мессенджеров.

## Состав выпуска

Сохраняется продукция RC1: точечный прогноз, карты облаков/осадков/температуры/
разброса температуры/ветра 100 м/радиации, cloudgram и сравнение вариантов осадков,
профиль и Skew-T, матрица срок × уровень, PNG/CSV/MP4/GIF, общие сценарии,
геолокация, сроки +1…+360, статус/отмена и защищённый API.
Высотные данные получаются через GCS/Zarr; BigQuery не используется для их имитации.

## Проверки и границы готовности

Добавлены проверки обоих пунктов выбора модели, идентичности средних полей и
метаданных двух представлений, маршрутизации в единый WN3-провайдер, кнопок
и прямых команд Telegram/MAX/VK; оба вида метеограммы проходят PNG/DOCX/PDF
проверки. Публикация проходит полный набор unit/contract/render тестов Python
3.10 и 3.11, проверку зависимостей и реальные GFS +24/+384 и surface smoke.
Точный проверенный Git tree, исходный commit и контрольные суммы приложены.

**Это предварительный выпуск, не подтверждение эксплуатации на сервере.**
Доступ к оперативным Google WN3, ADC/allowlist/Requester Pays, отправка в
production-чаты и deploy сервера не проверены этим выпуском. Google live
проверки следует выполнять с разрешённой учётной записью службы.

Полный набор WN3 требует Python 3.11+. На Python 3.10 работают GFS и WN3 BigQuery;
высотная GCS/Zarr-продукция возвращает понятное требование обновить Python.
Профили содержат 13 уровней; уровни ниже рельефа не маскированы. Диагностика
среднего профиля не равна средней диагностике ансамбля. WN3-маршруты,
вертикальная скорость, вероятности событий по всем членам и сравнение циклов
пока не реализованы. Данные модельные, не радиозонд и не наблюдения.
